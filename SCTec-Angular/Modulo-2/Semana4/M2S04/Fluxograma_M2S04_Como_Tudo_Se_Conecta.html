recalcula sozinho; guarda o resultado (cache)
effect · efeito colateral① localStorage.setItem(...)
② document.title = '(4) Mini Tarefas'
não devolve valor; roda de novo quando o signal muda
⬇o template lê com parênteses
Template{{ service.total() }} · [style.width.%]="percentual()"
quando o signal muda, só o trecho afetado atualiza

Quando uso cada um?

Preciso de…UsoNo projeto
guardar um valor que mudasignaltarefas, carregando, erro
calcular a partir de outroscomputedpendentes, percentual
fazer algo fora da telaeffectlocalStorage, título da aba
⚠️ Imutável: use update(l => [...l, nova]). Um push() não avisa ninguém.
⚠️ Parênteses: service.total() mostra o número. service.total mostra a função.
💡 Não use effect para calcular valores (use computed). O effect é para sincronizar com o mundo de fora (storage, título, log).

🔄 OnPush: quando o Angular atualiza um componente?

Algo aconteceu na aplicaçãoclique, resposta HTTP, timer, digitação…
⬇
❓ O componente é OnPush?
Default (Angular ≤ 21)verifica todos os componentes sempre. Simples, porém mais lento.
OnPush (padrão no v22)verifica o componente só se:
① um input mudou (nova referência)
② evento do próprio template
③ um signal lido nele mudou
④ o async pipe emitiu
🔑 Por isso trabalhamos assim: estado em signals, dados imutáveis (update com array novo) e Observables com async pipe. Com isso o OnPush “enxerga” tudo.
⚠️ Alterar o array com push() mantém a mesma referência: o OnPush não percebe e a tela fica velha.
No Angular 22, zoneless (sem zone.js) também é padrão. No projeto escrevemos ChangeDetectionStrategy.OnPush no CardTarefa e na Lista para fixar.
