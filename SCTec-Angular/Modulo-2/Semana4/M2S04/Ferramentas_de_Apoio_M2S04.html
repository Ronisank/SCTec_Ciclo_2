3. Ferramentas e sites úteis (gratuitos)

  • Documentação do Angular - angular.dev (inclui o *playground* no navegador).
  • RxJS - rxjs.dev: referência de operadores e a árvore de decisão "qual operador usar".
  • RxMarbles - rxmarbles.com: diagramas interativos de Observables (arraste as bolinhas e veja o resultado do debounceTime, combineLatest...).
  • StackBlitz - stackblitz.com: Angular no navegador, sem instalar nada.
  • Learn Git Branching - learngitbranching.js.org: tutorial interativo e visual de branches, merge e rebase.
  • Conventional Commits - conventionalcommits.org: a especificação das mensagens de commit.
  • SemVer - semver.org: versionamento semântico (as tags v1.0.0).
  • GitHub Docs - docs.github.com: Pull Requests, revisão de código e proteção de branches.

Atenção às versõesO curso usa o Angular 22. Nele: @Service() é o jeito padrão de criar um service (atalho de @Injectable({ providedIn: 'root' }), que continua válido e é necessário para injeção por construtor e escopos não-raiz); componentes novos nascem OnPush; aplicações novas são zoneless. Vídeos e tutoriais antigos usam @Injectable, app.component.ts, *.component.ts e zone.js: o conceito é o mesmo, só mudam os nomes. Se algo da doc não existir no seu projeto, confira a versão em ng version.
