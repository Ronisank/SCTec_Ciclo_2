Autenticação e autorização: login com JWT, interceptor, guards e perfis

24/11/2026 (terça) · Prática: ~65 min · Angular 22 · Repositório M2S07 → pasta Aula2_AutenticacaoAutorizacao/src · Executar no seu projeto-angular-sctec (com a Aula 1 concluída) · Precisa de internet (API DummyJSON)

Objetivo: criar o login com uma API real (DummyJSON), guardar a sessão em um AuthService com signals, enviar o token em cada requisição com um interceptor, proteger rotas com guards e liberar a área admin só para o perfil administrador.

Os TODOs

TODO 1Login no AuthService

Arquivo: src/app/core/auth/auth-service.ts (apague o throw provisório)
login(credenciais: Credenciais): Observable<Usuario> {
  return this.http.post<RespostaLogin>(`${API_AUTH}/login`, { ...credenciais, expiresInMins: 60 }).pipe(
    tap((resposta) => this._token.set(resposta.accessToken)),          // 1) guarda o token
    switchMap(() => this.http.get<UsuarioApi>(`${API_AUTH}/me`)),      // 2) pede o usuário (com o token)
    map(paraUsuario),                                                  // converte para o NOSSO formato
    tap({
      next: (usuario) => {
        this._usuario.set(usuario);
        this.salvarSessao();                                           // 3) persiste (F5 não desloga)
      },
      error: () => this.limparSessao(),
    }),
  );
}
