CONEXÃO 1 - Do import/export de arquivos ao NgModule e ao SharedModule

O que você já sabe

No Módulo 1 você separou funções em arquivos com export e import (ES Modules). Na Semana 5, cada componente listou no seu imports: [...] o que o template usa (ReactiveFormsModule, DatePipe, CepPipe).

O que a Semana 6 acrescenta

  • Um NgModule agrupa peças do Angular: imports (conhece) e exports (repassa).
  • O SharedModule junta o que várias páginas usam; cada página importa só ele.
  • Um barrel (index.ts) é o mesmo export do Módulo 1, reunindo uma pasta inteira.

Comparando o código

SEMANA 5 - cada página lista tudo
@Component({
  imports: [ReactiveFormsModule, UpperCasePipe,
            DatePipe, CepPipe],
})
export class CadastroAluno {}
SEMANA 6 - um módulo compartilhado
@Component({
  imports: [SharedModule],
})
export class CadastroAluno {}
// SharedModule: imports + exports
O que realmente mudou?A ideia de "o componente declara o que usa" continua. Mudou quem monta a lista: um módulo, uma vez só.

CONEXÃO 2 - De pages/ e caminhos relativos a features, aliases e lazy loading

O que você já sabe

Na Semana 5 o projeto tinha pages/, services/, pipes/ e models/, com rotas { path: 'contato', component: Contato } e imports como '../../services/cep-service'.

O que a Semana 6 acrescenta

  • Pastas por funcionalidade: core/, shared/, features/.
  • Aliases no tsconfig.json: @core, @shared, @features.
  • Rotas por feature e lazy loading: o código de cada página só é baixado quando o usuário entra nela.
SEMANA 5 - rota imediata
import { Contato } from './pages/contato/contato';

{ path: 'contato', component: Contato }
SEMANA 6 - rota sob demanda
{ path: 'contato', loadComponent: () =>
    import('@features/contato/contato')
      .then((m) => m.Contato) }
O que realmente mudou?A rota leva para a mesma página. Muda quando o navegador baixa o código: só na hora do clique.

CONEXÃO 3 - Do CSS do Módulo 1 ao SCSS organizado

O que você já sabe

No Módulo 1 você escreveu CSS com classes, cores repetidas e, na Semana 5, usou var(--azul) no styles.css do projeto.

O que a Semana 6 acrescenta

  • SCSS: variáveis, aninhamento com &, partials, @use, mixins, funções e mapas com @each.
  • A Angular CLI configurada para SCSS (angular.json).
  • O mapa SASS gera as mesmas variáveis CSS que você já usava.
SEMANA 5 - CSS repetido
.btn { background: var(--azul); }
.btn:hover { background: var(--azul-escuro); }
.btn-secundario { color: var(--azul); }
SEMANA 6 - SCSS aninhado
.btn {
  background: var(--azul);
  &:hover { background: var(--azul-escuro); }
  &-secundario { color: var(--azul); }
}
O que realmente mudou?O CSS que chega ao navegador é o mesmo. Muda a organização de quem escreve.

CONEXÃO 4 - Das media queries do Módulo 1 ao layout mobile-first com Grid

O que você já sabe

Você já usou Flexbox, @media e, na Semana 5, o cadastro tinha grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)).

O que a Semana 6 acrescenta

  • Mobile-first com min-width e um mixin de breakpoints.
  • Grid com auto-fill/minmax e grid-template-areas.
  • max-width, clamp(), object-fit e aspect-ratio.
MÓDULO 1 - media query escrita à mão
@media (max-width: 768px) {
  nav { flex-direction: column; }
}
SEMANA 6 - mixin mobile-first
nav {
  flex-direction: column;
  @include a-partir-de(md) { flex-direction: row; }
}
O que realmente mudou?Começamos pelo celular e os breakpoints moram em um lugar só.

CONEXÃO 5 - Do inject() e dos componentes próprios ao Angular Material e ngx-mask

O que você já sabe

Você criou componentes, usou inject(CepService), montou formulários reativos com validação e criou o pipe cep para formatar a exibição.

O que a Semana 6 acrescenta

  • Componentes prontos do Angular Material (mat-form-field, mat-card, mat-toolbar).
  • MatSnackBar: um service pedido com inject(), como o CepService.
  • ngx-mask: formata enquanto digita (o pipe formata só na exibição).
SEMANA 5 - campo feito à mão
<label for="cep">CEP</label>
<input id="cep" formControlName="cep" />
@if (invalido('cep')) {
  <small class="erro">8 números</small>
}
SEMANA 6 - Material + máscara
<mat-form-field appearance="outline">
  <mat-label>CEP</mat-label>
  <input matInput formControlName="cep" mask="00000-000" />
  <mat-error>8 números</mat-error>
</mat-form-field>
O que realmente mudou?O Reactive Forms é o mesmo (formControlName e Validators). Muda a camada visual, agora pronta e acessível.
