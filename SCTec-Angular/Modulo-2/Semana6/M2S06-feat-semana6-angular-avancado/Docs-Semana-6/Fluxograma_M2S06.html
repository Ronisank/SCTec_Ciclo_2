5. Qual ferramenta usar? Guia de decisão
PerguntaUsePor quê
Arquivo usado uma vez no app (layout, service global)?core/Não pertence a nenhuma feature
Peça reutilizável, sem regra de negócio?shared/Qualquer feature pode usar
Tela ou regra de um assunto (cursos, alunos)?features/<assunto>Tudo do assunto mora junto
Várias páginas importam a mesma lista?SharedModule (ou array de imports)Uma lista só, com exports
Página que nem todo usuário abre?loadComponent / loadChildrenBundle inicial menor
Valor que muda em tempo real (tema)?Variável CSS (--azul)Existe no navegador
Valor/bloco reaproveitado na compilação?Variável, mapa ou mixin SASSOrganiza o código-fonte
Colunas que se ajustam sozinhas?Grid auto-fill + minmaxSem media query
Imagens de tamanhos diferentes no mesmo card?aspect-ratio + object-fit: coverMesma altura, sem distorcer
Mudar o visual de um componente Material?mat.*-overridesAPI pública; sobrevive ao ng update
Formatar enquanto digita?ngx-mask (diretiva)Pipe formata só a exibição
