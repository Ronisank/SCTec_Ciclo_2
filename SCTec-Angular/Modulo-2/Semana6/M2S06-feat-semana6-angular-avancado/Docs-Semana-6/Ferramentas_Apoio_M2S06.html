6. Para praticar fora da aula

  • Aula 1: crie a feature features/turmas com turmas.routes.ts, um service com signal e rota lazy. Confira o novo chunk no ng build.
  • Aula 2: crie um mixin @mixin ate($bp) com max-width e um tema escuro trocando as variáveis CSS em .tema-escuro.
  • Aula 3: use mat-chip para mostrar a área de cada curso e um MatDialog com os detalhes do curso.
