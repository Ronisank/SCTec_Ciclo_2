## 📖 Descrição do Projeto

O projeto **PATINHAFELLIZ** consiste no desenvolvimento de uma landing page para um pet shop fictício, com o objetivo de apresentar serviços, informações institucionais e permitir contato e agendamento de serviços.

A página foi construída utilizando **HTML, CSS e JavaScript**, com foco em:

* Estruturação semântica
* Layout moderno e responsivo
* Interatividade com o usuário

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** → Estrutura da página
* **CSS3** → Estilização e layout
* **JavaScript (DOM)** → Interatividade
* **Font Awesome** → Ícones
* **Google Fonts** → Tipografia
